# Install FlowPlotGUI

FlowPlotGUI is the visual editor for FlowPlot templates. Download the package appropriate for your system from the release assets.

| Platform | Package | Download | Use |
| --- | --- | --- | --- |
| macOS | DMG | [Download DMG](https://github.com/Manwe314/FlowPlot/releases/download/v0.9.8/FlowPlotGUI-0.9.8-macOS.dmg) | Open the DMG and drag `FlowPlotGUI.app` to Applications. See the macOS note below. |
| Windows | Installer | [Download installer](https://github.com/Manwe314/FlowPlot/releases/download/v0.9.8/FlowPlotGUI-0.9.8-Windows.exe) | Run the installer. |
| Windows | Runtime ZIP | [Download ZIP](https://github.com/Manwe314/FlowPlot/releases/download/v0.9.8/FlowPlotGUI-0.9.8-Windows-Runtime.zip) | Unzip and run the included executable. |
| Linux | AppImage | [Download AppImage](https://github.com/Manwe314/FlowPlot/releases/download/v0.9.8/FlowPlotGUI-0.9.8-x86_64.AppImage) | Mark it executable, then run it. |
| Linux | Debian package | [Download `.deb`](https://github.com/Manwe314/FlowPlot/releases/download/v0.9.8/flowplotgui_0.9.8_amd64.deb) | Install it with your package installer. |
| Linux | Tarball | [Download `.tar.gz`](https://github.com/Manwe314/FlowPlot/releases/download/v0.9.8/FlowPlotGUI-0.9.8-Linux.tar.gz) | Extract it and run the included executable. |

## macOS security notice

FlowPlotGUI is currently unsigned and not notarized. After moving `FlowPlotGUI.app` to Applications, macOS may block its first launch. In Finder, Control-click the app, choose **Open**, then confirm **Open**. If macOS still blocks it, go to **System Settings → Privacy & Security** and select **Open Anyway** for FlowPlotGUI. This creates an exception for this app only; do not disable Gatekeeper globally.

Once it is running, continue with [Use FlowPlotGUI](gui-usage.md).
